# Thực hành: Xây dựng Trang Chủ với Bootstrap

Dự án thực hành sử dụng **Bootstrap 5.3.3** kết hợp **Font Awesome 6.5.2** để tạo bố cục trang chủ linh hoạt và hiện đại.

## Các thành phần đã triển khai
1. **Bước 1**: Nhúng Bootstrap 5.3.3 CSS/JS và Font Awesome 6.5.2 qua CDN.
2. **Bước 2 (Navbar)**:
   - Sử dụng `navbar navbar-expand-lg navbar-dark bg-dark`.
   - Kết hợp các icon Font Awesome (`fas fa-home`, `fas fa-info-circle`, `fas fa-cogs`, `fas fa-envelope`).
3. **Bước 3 (Carousel Slideshow)**:
   - Sử dụng component `carousel slide` có indicators, caption và nút chuyển slide (prev/next).
4. **Bước 4 (Flexbox Section)**:
   - Sử dụng Flexbox utility (`d-flex justify-content-center align-items-center`) để căn giữa nội dung hoàn hảo.
5. **Bước 5 (Contact Form)**:
   - Sử dụng Bootstrap Form Controls (`form-label`, `form-control`, `btn-primary`).
6. **Footer**:
   - Chân trang hiển thị thông tin bản quyền.

## Chạy thử nghiệm
Mở tệp `index.html` trong bất kỳ trình duyệt web nào.
